About this site


This site exists as a convenience tool for organisers and delegates. After I felt that the catalog would be better if it was in the form of a website (as opposed to a Google Sheet), I built this site.

Organisers

This site is not meant to be a guide on how to organise a competition. I will ignore all change requests related to material for organisers. SNZ is currently working on an organiser guide, which will be linked here when finished.

Reporting a problem

If something needs to be changed (eg, the venue is no longer open for bookings, or the website is not available), please go this form and submit a change request. Alternately, if you're a developer, feel free to send a Pull Request to this project's GitHub page. I aim to respond to all change requests within 24 hours.
